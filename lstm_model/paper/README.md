# Paper draft — how to build and what's verified

**Compile:** upload this `paper/` folder *plus* the `figures/` folder
(sibling directory) to [Overleaf](https://overleaf.com) keeping the layout:

```
project/
  paper/main.tex      <- set this as the main document
  figures/fig1_*.pdf ... fig7_qualitative.png
```

(or just put the figure files next to `main.tex` and delete the
`\graphicspath` line). Compiler: pdfLaTeX. No special packages needed.

**Every number in the tables/prose is computed from result files in
`lstm_model/`** — regenerate figures and re-verify anytime with:

```
python3 make_figures.py
```
